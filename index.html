# Key Term Frequency Normalized Weight (TF)
1. Tokenization & Sentence Segmentation

Boundary Detection:

  • Sentence boundary detection via lookbehind regex: (?<=[.!?])\s+
  • Multi-pattern deterministic matchers for definition structures (Term: Def, X is defined as Y, X refers to Y).
  • Operates locally in linear time with zero GPU VRAM or cloud token cost.
2. Frequency Distribution & Filtering

Hash Table Architecture:

  • Hash Set: English stopword filtering in average O(1) time.
  • Hash Map: Token frequency distribution computed in O(N) linear time over total document words N.
  • Normalized term weights scaled linearly: TF(w) = freq(w) / max_freq.
3. Sentence Scoring & Ranking

Density & Position Weighting:

  • Combines word frequency density with positional and definition weight bonuses.
  • Top-K sentence selection using comparison sorting in O(S log S).
  • Secondary chronological index sort in O(K log K) preserves logical lecture narrative.
4. Ingestion & Export Engine

Data Processing:

  • Local Privacy: 100% computed client-side with zero external API calls or data transmission.
  • Factuality: Extractive summarization selects verbatim sentences, eliminating hallucinations.
  • Document Ingestion: Multi-page PDF text extraction via PDF.js with automated paragraph un-wrapping.
